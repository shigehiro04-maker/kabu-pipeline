# 需給分析（信用残・空売り・投資部門別）

JPX（日本取引所グループ）と日本証券金融（日証金）が**無料で公開しているデータ**と、手元の株価CSVだけで、

1. **銘柄ごと**の信用買残・信用売残・信用倍率、その増減、買い方・売り方の評価損益率
2. **日証金**の貸借倍率・逆日歩、**大口の空売り**（残高割合0.5%以上の報告）
3. **出来高・売買代金**、価格帯別出来高（上値のしこり）
4. **市場全体**の信用残・信用倍率（2002年〜）、空売り比率、**投資部門別**の売買（海外投資家・個人・信託銀行…）
5. それらをまとめた**需給スコア**と**需給判定**（踏み上げ候補・好需給・買残重い・投げ警戒…）

を作り、ファンダメンタル分析のスコア一覧・スクリーニングにも結合します。毎営業日 `run_daily.sh` から自動で更新されます（約1〜2分）。

## 見る場所

| もの | 場所 |
|---|---|
| ダッシュボード | `data/charts/jukyu.html`（トップ画面のカード「需給分析」から。`jukyu.html#7203` で銘柄を直接開く） |
| Excel | `需給分析/output/需給分析_YYYY-MM-DD.xlsx`（読み方・銘柄一覧・候補別・業種別・市場全体・投資部門別・大口空売り。60日で自動削除） |
| スコア一覧の列 | `fundamentals/jukyu.csv` → スコア一覧の「信用買残(株)」〜「需給判定」。ファンダメンタル分析の表示「需給」、銘柄詳細の「需給」カード、スクリーニング「好需給株」「信用買残が重い株」 |
| ログ | `logs/jukyu_YYYYMM.log` |

## データの出どころ（すべて無料・ログイン不要）

| データ | 出どころ | 更新 | 保存先（需給分析/data/） |
|---|---|---|---|
| 銘柄別信用取引残高（全銘柄・一般/制度別・約定金額つき） | JPX 信用取引残高等 › 銘柄別信用取引残高（PDF） | 毎営業日16時ごろ（前営業日申込分） | `margin/申込日.csv`、小計は `margin_total.csv` |
| 日々公表銘柄・規制銘柄などの印 | JPX 日々公表銘柄等信用取引残高（Excel） | 毎営業日 | `flags.csv` |
| 貸借取引残高（融資・貸株）・品貸料（逆日歩） | 日証金 `zandaka.csv`・`shina.csv` | 毎営業日 | `taisyaku/`・`shina/` |
| 空売り残高（0.5%以上の報告） | JPX 空売りの残高に関する情報（xls） | 毎営業日17時ごろ | `short_positions/` |
| 空売り比率（市場・33業種） | JPX 空売り集計（日次PDF） | 毎営業日 | `short_market.csv`・`short_sector.csv` |
| 投資部門別 株式売買状況 | JPX 投資部門別売買状況（週次Excel） | 毎週木曜15時半ごろ | `investor_weekly.csv`（千円） |
| 信用取引現在高（市場全体・2002年〜） | JPX 信用取引現在高 過去推移表（xls） | 毎週 | `margin_market_weekly.csv` |

**大事な注意**：JPXのページには**銘柄別の信用残が直近5営業日分しか置かれません**。過去にさかのぼって取れないので、
このツールは毎日取って `data/margin/` に貯めます。「買残5日変化」「買残20日変化」は、貯まるまで空欄です（5営業日・20営業日後から出ます）。
空売り集計・空売り残高・投資部門別はバックナンバーから約1年分（投資部門別は約2年分）を初回に取り込み済みです。

## 主な指標の作り方

| 指標 | 計算 |
|---|---|
| 信用倍率 | 買残÷売残（株数）。売残0は空欄 |
| 買残回転日数 | 買残÷25日平均出来高。何日分の出来高に当たる買残が残っているか |
| 信用買い評価損益率 | 買残×終値÷買残の約定金額−1（JPXの金額は約定代金）。売り方は 1−売残×終値÷売残の約定金額 |
| 市場の信用倍率・評価損益率 | 普通株の合計（時価ベース）。日ごとの値は `data/market_daily.csv` に残し、後から書き換えない |
| 貸借倍率 | 日証金の融資残÷貸株残。逆日歩の年率は 品貸料÷品貸日数÷貸借値段×365 |
| 大口空売り比率 | 報告者（＋委託者・ファンド）ごとの最新の残高割合のうち0.5%以上を合計 |
| 価格帯別出来高 | 直近60日の (高値+安値+終値)/3 の帯（20本）に出来高を積む。上値出来高比率＝現在値より上の帯の出来高の割合 |
| 需給スコア | 50を中立に、信用倍率・買残回転日数・売残の厚さ・評価損益率・買残の増減と株価の向き・逆日歩・貸株超過・大口空売り・上値のしこり・出来高を伴う上昇を足し引き（0〜100）。内訳は「需給メモ」列。大口空売り2%以上は −3（2026-10-10 に +3 から変更。過去1年の検証で、多い銘柄ほどその後に負けやすかった。`平均回帰実装_第3章_20261010/` の検証2-1） |

株式分割・併合があった銘柄は、`data/splits.csv`（株価CSVと同じ台帳）で分割前の信用残の株数をいまの株数ベースにそろえます。

## 需給判定

| 判定 | 条件 |
|---|---|
| 規制・注意 | JPXの信用規制・日々公表銘柄、不明確情報の注意喚起など（印：規・日・○） |
| 踏み上げ候補 | 信用倍率1.5倍未満・売残が出来高2日分以上・逆日歩または大口空売り1%以上・株価が25日線の上・買残が出来高10日分未満・スコア55以上 |
| 好需給 | 需給スコア65以上 |
| 買残重い | 信用倍率8倍以上かつ買残が出来高7日分以上 |
| 投げ警戒 | 買い方の評価損益率−20%以下かつ買残が出来高5日分以上 |
| 需給悪い／中立 | スコア35以下／それ以外 |

需給スコアと判定は**経験則による目安で、まだ過去データで検証していません**（銘柄別の日次信用残が貯まってから、
判定後の値動きを検証して重みを見直す予定）。投資判断はご自身で。

## 手動で実行

```bash
bash ~/株分析/需給分析/run_jukyu.sh                 # 取得＋分析（通常）
bash ~/株分析/需給分析/run_jukyu.sh --backfill      # バックナンバー（約1年分）も取り直す
~/株分析/.venv/bin/python ~/株分析/需給分析/analyze_jukyu.py   # 通信なしで分析だけ
~/株分析/.venv/bin/python ~/株分析/需給分析/fetch_jukyu.py --only margin,taisyaku   # 一部だけ取得
```

`--only` に使える名前：margin（銘柄別信用残）・flags（日々公表の印）・taisyaku（日証金）・sp（空売り残高）・ss（空売り集計）・inv（投資部門別）・mkt（信用取引現在高）

## うまくいかないとき

- ログ（`logs/jukyu_YYYYMM.log`）に「総合計の買残に対する読み取り率」が出ます。99%を大きく下回ったら、JPXのPDFの様式が変わった可能性があります（`jk_parse.py` の `parse_margin_pdf`）。
- 投資部門別は2026年9月に様式が変わりました（新様式 `stock_1_w_*.xlsx` と旧様式 `stock_val_1_*.xls` の両方を読みます）。また変わると「見出しが想定とちがいます」とログに出ます。
- 市場全体の日次評価損益率を作り直したいときは `data/market_daily.csv` を消してから `analyze_jukyu.py` を実行します（過去分は配当調整済みの株価で計算し直されます）。

## ファイル構成

```
需給分析/
├── run_jukyu.sh         run_daily.sh から呼ばれる（取得→分析）
├── fetch_jukyu.py       JPX・日証金から取得して data/ に蓄積
├── jk_parse.py          PDF・Excel・CSV の読み取り
├── analyze_jukyu.py     指標・スコアの計算、jukyu.csv・Excel
├── report_jukyu.py      ダッシュボード（data/charts/jukyu.html・jukyu/<コード>.js・jukyu_summary.json）
├── jukyu_page.html      ダッシュボードのひな形（HTML・JS）
├── jukyu_style.css      ダッシュボードの見た目（CSS）
├── data/                取得したデータ（消さない。銘柄別信用残はここにしか残らない）
└── output/              Excel
```
