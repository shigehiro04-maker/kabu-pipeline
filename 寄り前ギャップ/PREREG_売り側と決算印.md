# 事前登録：寄り前ギャップの「売り側」と「決算翌日の印」（2026-10-12 固定。記録が始まってからは変えない）

『Algorithmic Trading』第7章の検証（`../日中モメンタム_第7章_20261012/README_日中モメンタム_第7章.md`）で、
- 上に窓を開けた銘柄は日中に戻る（k=1・始値<20日線で 2016-12〜 1日 −49bp、t=−5.9。第4章の「下の窓を買う」の鏡写し）
- 決算翌日の窓だけは戻らず続きやすい（2024/9〜、件数が少なく未確定）
ことが分かった。**お金を入れずに**記録し、実際の値動きでも同じかを確かめる。買い側（第4章）のルールは一切変えない。

## ルール A：売り側（上の窓を売る）
| 項目 | 内容 |
|---|---|
| 運用対象 | 買い側と同じ（前月末に、60日の売買代金の中央値 2億円以上・時価総額 300億円以上の内国株） |
| 売る条件 | 当日始値 > 前日高値 ×（1 + k × σ90）、かつ 当日始値 < 20日移動平均（σ90・20日線は買い側と同じ定義） |
| 除外 | 寄らず（高値＝安値）、出来高0、寄りからストップ高に張り付き（始値＝高値 かつ 前日終値比 +13%以上） |
| 売り方 | 条件を満たした銘柄のうち 始値÷前日高値 が大きい順に10銘柄を、寄付きで同額ずつ売り、大引けで買い戻す |
| k | 1（主）と 0.5（参考） |
| 損益 | 売りの向き（株価が下がればプラス）。コスト・貸株料・逆日歩は引かない。空売りできる銘柄かは確認しない |

## ルール B：決算翌日の印
| 項目 | 内容 |
|---|---|
| 印を付ける銘柄 | 判断日 〜 対象日の前日 に決算発表（予定）日がある銘柄 |
| 発表日のデータ | JPX「決算発表予定日」の Excel（`株分析/kessan*.xlsx` または `株分析/決算発表予定日/*.xlsx`。同じ決算期は「現在」日付の新しい版）と、J-Quants 決算サマリーの実際の開示日 |
| 使い方 | 売買の条件は変えない。日次の記録に「決算翌日の銘柄を除いて選んだ場合」の損益（決算除く_損益_pct）を並べる（買い・売りとも） |

記録の開始：2026-10-13 の寄付き（判断日 2026-10-09）から。

## 判定（12か月目＝2027-10 末の記録で1回だけ。途中で基準を変えない）
**売り側**を「実際のお金で小さく始める候補」にするのは、次をすべて満たしたとき（k=1）。
1. 1取引平均（コスト前）≥ +20bp（片道10bpのコストを引いても残る水準）
2. 日次損益の平均 > 0 で t ≥ 1.5
3. 買い側（k=1）との日次相関 ≤ 0.20
4. 記録した取引のうち、実際に空売りできた（制度信用の貸借銘柄、または一般信用で売れた）銘柄だけで見ても 1. を満たす（判定時に貸借銘柄の一覧で確認する）

**決算翌日の印**で買い側のルールを変える候補にするのは、次をすべて満たしたとき（このときは新しい事前登録をしてから変える）。
1. 買い k=1 で「決算除く」の累計 > 「含む」の累計
2. 印の付いた取引が 30件以上あり、その1取引平均 < 0

## 途中でやめる基準
- 売り k=1 の累計が記録開始からの最高値より −35% 下がったら記録を止めて見直す（再現の最大DD −24.7% の約1.4倍）
- 6か月目（2027-04 末）は確認だけで、判定はしない

## 注意（事前に分かっている弱点）
- 空売りは信用取引が必要。貸借銘柄でない銘柄、逆日歩、一般信用の在庫切れで実際には売れないことがある
- 寄り前の気配と実際の始値はずれる。記録は「実際の始値で売れた」とした場合
- 2023〜2025年は年 +8〜+14% と弱かった。強い年（2020・2022・2026）に偏っている
- JPX の決算発表予定日は、毎日の処理で自動取得する（2026-10-12 承認、`fetch_kessan_schedule.py`）。取得に失敗した日は前回までのファイルを使うので、印が抜けることがある。処理ログに「予定表の最終日」を出す
