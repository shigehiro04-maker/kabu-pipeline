# 東証全銘柄 ファンダメンタル分析

`fetch_fundamentals.py` が集めた決算データ（3,706銘柄）を、スコア・スクリーニング・
業種別集計に加工し、ブラウザで探せるダッシュボードにするツールです。

```
fundamentals_latest.csv  ┐
                         ├→  analyze_fundamentals.py  →  スコア・スクリーニング・集計
bank_capital.csv         ┘              ↓
（fetch_bank_capital.py）  make_fundamental_dashboard.py  →  ダッシュボードHTML
```

---

## 使い方

```bash
cd ~/株分析

./.venv/bin/python analyze_fundamentals.py          # 分析（3秒）
./.venv/bin/python make_fundamental_dashboard.py    # ダッシュボード生成（1秒）
open data/charts/fundamentals.html
```

日次ジョブに組み込み済みなので、**普段は何もしなくても毎営業日その日の終値で作り直されます**
（`run_daily.sh` → `run_fundamentals.sh`）。銀行のバーゼル自己資本比率だけは年1回しか変わらないため、
同じジョブが月1回だけ様子を見にいきます。

### 自動更新の仕組み（2026-09-15 に見直し）

launchd（`com.stockfetch.daily`）が次のタイミングで `run_daily.sh` を呼びます。

- Macの起動・ログイン時
- **平日 16:30 / 19:00 / 22:00** — 16:30に取りこぼしても後の回で拾い直します。
  データが最新なら数秒で終わるので、何度走っても無駄になりません。
- 二重起動は `logs/run_daily.lock` で防いでいます（6時間以上前のロックは残骸とみなして自動で解除）

実行中はスリープさせないよう `caffeinate -i` で包み、`ProcessType` は `Standard` にしています。
以前は `Background` だったためスリープ中に強く抑制され、**同じチャート生成が55秒〜9,296秒とばらついて
いました**（設定変更後は55秒で安定）。

## スクリーニング（条件ビルダー）

ダッシュボードの「スクリーニング」タブで、**条件を自分で組んで絞り込めます**。

- 上のボタン（割安株・成長株・高配当株・安定優良株・高収益企業・なごちょう式・マルチバガー候補）を押すと条件が入り、
  そこから数値を変えられます
- 「＋ 条件を追加」で好きな指標を足せます。片側だけの指定（下限だけ／上限だけ）も可
- 条件は上から順に**すべて満たす**銘柄が残ります。値が無い銘柄は満たさない扱いです
- 「CSVで保存」で、その時点の結果をExcelで開ける形に落とせます

| プリセット | 条件 | 該当 |
|---|---|---|
| 割安株 | PER≦15、PBR≦1、流動比率≧1倍、負債資本比率≦1 | 728社 |
| 成長株 | 増収率≧10%、ROE≧10%、純利益率≧5% | 450社 |
| 高配当株 | 配当利回り≧3%、配当性向25〜75%、1株当たりフリーCF≧0 | 513社 |
| 安定優良株 | ROE≧10%、流動比率≧1.5倍、負債資本比率≦0.5、ベータ(1年)≦1 | 575社 |
| 高収益企業 | ROE≧15%、ROTC≧10%、EBITDAマージン≧10%、純利益率≧5% | 410社 |
| なごちょう式 | ネットキャッシュ倍率<1、売上高CAGR≧10%、自己資本比率≧50%、流動比率≧200%、営業利益率≧10%、配当利回り≧3%、PER≦10、PBR≦1 | 1社 |
| マルチバガー候補 | ROE≧15%、営業利益率≧10%、フリーCF>0、増収率と売上高CAGRがともに≧5%、FCF利回りと時価総額は業種別基準（下記） | 47社（うちエントリーOK 6社） |
| マルチバガー論文準拠 | 時価総額20〜3,000億円・PBR≦2.5・営業黒字・FCF利回り>0・総資産の伸び≦EBITDAの伸び・FCF黒字の期が半分以上。論文スコア順 | 852社（うち安値圏151社） |

**負債資本比率**は有利子負債÷自己資本（D/Eレシオ）です。買掛金や引当金は含みません。
**流動比率**は画面では%で持っているので、1倍=100、1.5倍=150として指定します。
**ベータ(1年)**は直近250営業日で計算した新しい列です（3年ベータも別列で残しています）。
**ネットキャッシュ倍率**は時価総額÷換金性資産（＝流動資産−負債合計）です。1倍未満なら、
時価総額で会社を丸ごと買っても、負債を全額返したあとの流動資産のほうが大きいことになります。
換金性資産がマイナスの会社は倍率を出さず対象外にしています（算出できたのは2,578社）。
なごちょう式は条件を重ねるたびに1,077→532→422→262→40→9→4→**1社**と絞られます。
広げたいときはボタンを押したあとに数値を変えてください（倍率の上限を2倍にすると4社）。

### マルチバガー候補（論文ベース）

Yartseva (2025) *The Alchemy of Multibagger Stocks*（米国で15年間に10倍以上になった464銘柄の
動的パネル分析）の実証結果を、日本株と手元のデータに合わせて条件にしたものです。

論文の結論はおおむね次のとおりです。

- **フリーCF利回り（FCF/P）と簿価/時価（B/M）が将来リターンの最大の説明変数**。PERは役に立たない
- 小型ほど有利（低ベース効果）。収益性はROA・EBITDAマージンが有意だが係数は小さい
- **資産の伸びがEBITDAの伸びを上回る「身の丈を超えた投資」は翌年リターンを4〜11%pt下げる**。
  投資そのものは悪ではなく、EBITDAが追いついているかが分かれ目
- **52週高値に近いほど翌年のリターンは低い**。安値圏で拾うほど良い
- **増収率・EPS成長率・FCF成長率そのものには将来リターンの予測力が無い**（5年CAGRでも同じ）
- 利上げ局面は翌年リターンを約10%pt下げる

**基本条件**は ROE≧15%・営業利益率≧10%・フリーCF>0・増収率と売上高CAGRがともに≧5%。
そのうえでFCF利回りと時価総額の基準を業種で変えています。ソフトウェアは複製コストがほぼゼロ、
小売は在庫の改善余地が大きい、というように稼ぎ方が違うため、一律の基準だと判断を誤るからです。

| 区分 | 対象業種 | FCF利回り | 時価総額 |
|---|---|---|---|
| 情報通信 | 情報・通信業 | ≧4% | 500〜3,000億円 |
| サービス | サービス業 | ≧5% | 300〜2,000億円 |
| 小売 | 小売業 | ≧6% | 200〜1,500億円 |
| 製造業 | 食料品・化学・医薬品・機械・電気機器など16業種 | ≧5% | 500〜5,000億円 |
| その他 | 建設・不動産・卸売・運輸・電気ガスなど | ≧5% | 100〜5,000億円 |

金融4業種（銀行・保険・証券・その他金融）と決算が古い銘柄は対象外です。

**適合度スコア（最大95点）**

| 区分 | 点 | 中身 |
|---|---|---|
| 評価値 | 40 | P/FCFの水準28点（≦10倍=28／10〜20=22／20〜33=12／>33=4）＋ 過去4期のフリーCFが黒字だった割合×12点 |
| エントリー | 30 | 52週レンジ位置20点（0〜30%=20／30〜50%=15／50〜70%=8／>70%=0）＋ 6か月騰落率10点（−30〜−5%=10／−5〜+5%=7／+5〜+15%=3／>+15%=0／<−30%=5） |
| 品質 | 20 | 総資産CAGR−EBITDA CAGR が12点（≦0=12／0〜+5%pt=6／>+5=0）＋ 投資効率8点（FCF÷設備投資 または 設備投資÷売上） |
| 金利調整 | ±  | `--rate-env 逆風`で−10点、`中立`で0（既定）、`追い風`で+5点 |

**エントリー判定**が「OK」なのは、スコア70点以上・52週レンジ位置30%以下・6か月騰落率+5%以下・
フリーCFプラスをすべて満たす銘柄です。基本条件は満たすがタイミングが合わない銘柄は「待ち」になります。

```bash
./.venv/bin/python analyze_fundamentals.py --rate-env 逆風   # 利上げ局面とみて10点差し引く
```

**注意点。**
設備投資額は標準化財務諸表に行が無いため「営業CF − フリーCF」で戻しています
（Yahooのフリーキャッシュフローが「営業CF − 設備投資」の定義のため。実データ3,640銘柄すべてで
マイナスにならず、売上比の中央値も2.9%と実態に合います）。
成長率は最大4期しか無いので3年の年平均です。論文が「増収率には予測力が無い」としている一方で
基本条件に増収率5%以上を入れているのは実務上の判断で、スコアには効かせていません。
政策保有株の売却収入や不動産売却益の除外は、手元のデータに内訳が無いため行っていません。
そして何より、**論文は米国株の分析であり、日本株で同じ結果になる保証はありません。**

### マルチバガー論文準拠

上の「マルチバガー候補」は実務判断で ROE≧15%・増収率≧5% などを足しているため、論文が
「予測力が無い」とした変数も効いています。こちらは**論文が有意とした変数だけ**で絞り込みます
（`analyze_fundamentals.py` の `add_multibagger_paper`）。

| 必須条件 | 論文の根拠 |
|---|---|
| 金融4業種・決算が古い銘柄を除く | — |
| 時価総額20〜3,000億円 | 小型ほど有利（<$250M が最良）。20億未満は流動性のため除外 |
| PBR 0超〜2.5倍（B/M≧0.40） | Fama-Frenchソートで B/M>0.40 かつ営業黒字なら超過リターンの確率が高い |
| 営業黒字 | 同上 |
| FCF利回り>0 | FCF/P が最大の説明変数 |
| Invダミー=0（直近期の総資産成長率≦EBITDA成長率） | 資産の伸びがEBITDAを上回ると翌年 −4〜−11%pt。論文と同じく単年で判定。前期EBITDA赤字→今期黒字は合格 |
| 過去の期の半分以上でFCF黒字 | **論文外**。単年FCFの一時的な振れを除くノイズ対策 |

**論文スコア（100点）**は条件を満たした銘柄の中でのパーセンタイル×重みです。
FCF利回り30・B/M25・小型15・52週安値圏15・6か月下落10・ROA5。重みは係数の大きさの順を反映した目安です。
条件外の銘柄は空欄になります。

**論文エントリー**が「安値圏」なのは、52週レンジ位置30%以下かつ6か月騰落率0%以下の銘柄です。
ダッシュボードでは「マルチバガー論文準拠」「論文準拠・安値圏」の2つのボタンで呼び出せます（論文スコア順に並びます）。

**論文注意**には「FCF利回り40%超」「資産かEBITDAが急変」「6か月で−40%超の急落」が出ます。
運転資本の出入り・資産売却・M&Aなどの一時要因を決算書で確認してください。

増収率・ROE・PER・負債比率・自社株買いは論文で有意でなかったため使っていません。
利上げ局面の影響（翌年約−10%pt）は全銘柄共通なので順位には入れていません。
上位には時価総額100億円未満・ROA1〜2%の小型株が多く入ります。論文は米国株の分析で、日本株で同じ結果になる保証はありません。

絞り込みに使える指標は33項目（PER・PBR・PSR・EV/EBITDA・配当利回り・配当性向・ROE・ROA・
ROTC・営業利益率・純利益率・自己資本比率・流動比率・インタレストカバレッジ・営業CFマージン・
フリーCF利回り・増収率・営業増益率・純利益成長率・時価総額・ベータ・年率ボラティリティ・
売上高CAGR・平均税引前利益率・250日騰落率・ネットキャッシュ倍率・換金性資産・
6項目の評価・評価平均・総合評価）。

画面上部の市場・業種・時価総額・「赤字を除く」などの絞り込みは、この条件と**重ねて**効きます。

## 追加した指標

| 指標 | 計算 | 見るポイント |
|---|---|---|
| EV/EBITDA | (時価総額＋有利子負債−現金) ÷ 償却前営業利益 | 会社を丸ごと買うのに実質何年分の稼ぎが要るか。**借金の多い会社はPERより割高に、現金の厚い会社は割安に**出る |
| ROTC | 営業利益 ÷ 投下資本 | ROEと違い借金も分母に入るので、レバレッジで見かけを良くできない |
| インタレストカバレッジ | 営業利益 ÷ 支払利息 | 利払いの何倍を稼げているか。低いほど金利上昇に弱い |
| ネットキャッシュ | 現金 − 有利子負債 | プラスなら実質無借金 |
| 換金性資産 | 流動資産 − 負債合計 | 負債を全額返したあとに残る換金しやすい資産。投資有価証券は加えていない |
| ネットキャッシュ倍率 | 時価総額 ÷ 換金性資産 | 1倍未満は時価総額より換金性資産のほうが大きい状態 |
| ベータ | 直近3年の日次リターンを市場に回帰 | 1より大きいほど市場より値動きが荒い |
| 年率ボラティリティ | 日次リターンの標準偏差 × √252 | 値動きの大きさそのもの |
| 52週レンジ位置 | (終値 − 52週安値) ÷ (52週高値 − 52週安値) × 100 | 0%が安値・100%が高値。論文では高値に近いほど翌年リターンが低い |
| 125日騰落率 | 125営業日（約6か月）前比 | マルチバガー判定のエントリー条件に使う |
| P/FCF | 時価総額 ÷ フリーCF | FCF利回りの逆数（20倍＝利回り5%） |
| 設備投資額 | 営業CF − フリーCF | 標準化財務諸表に単独の行が無いので差し戻している |
| FCF/設備投資 | フリーCF ÷ 設備投資額 | 投資1円あたり何円が手元に残るか |
| 成長ギャップ | 総資産CAGR − EBITDA CAGR | プラスは身の丈を超えた投資。論文の Inv ダミーにあたる |
| FCF黒字比率 | 直近4期のうちフリーCFがプラスだった期の割合 | キャッシュ創出の安定性 |

EV/EBITDA・ROTC・インタレストカバレッジは**銀行・保険では意味を成さない**ため空欄になります。

### Fスコア（ピオトロスキー）

収益性・財務の安全性・営業効率について9項目を判定し、条件を満たせば1点、満たさなければ0点として
合計した0〜9点の指標です。**2026年10月6日に TradingView の定義に合わせて組み直しました。**
総合評価（四季報式）とは独立していて、`スコア一覧.csv` に `Fスコア` と9項目の内訳
（`F1純利益` 〜 `F9資産回転率`）、代用データを使った項目 `F代用`、判定できなかった理由 `Fデータ品質` が入ります。

| 番号 | 区分 | 項目 | 1点の条件 |
|---|---|---|---|
| F1 | A 収益性 | 純利益 | 直近期の当期純利益がプラス |
| F2 | A 収益性 | 営業CF | 直近期の営業CFがプラス |
| F3 | A 収益性 | ROA変化 | ROA（当期純利益÷平均総資産）が前期を上回る |
| F4 | A 収益性 | 収益の質 | 営業CFが特別損益前の純利益を上回る |
| F5 | B 財務 | 長期借入金 | 長期借入金÷平均総資産が前期より低い |
| F6 | B 財務 | 流動比率 | 流動比率が前期を上回る |
| F7 | B 財務 | 株式発行 | 直近期に新株発行（株式の発行による収入）が無い |
| F8 | C 営業効率 | 売上総利益率 | 売上総利益率が前期を上回る |
| F9 | C 営業効率 | 資産回転率 | 総資産回転率（売上高÷平均総資産）が前期を上回る |

平均総資産は「期首と期末の平均」。前期の平均に前々期末の総資産を使うので、3期分の決算が要ります。

**Fスコアは2種類あります。** `Fスコア` はすべて実績ベース（上の表）。
`予想Fスコア` は下の「予想Fスコア」の節のとおり、マネックス証券「復活Fスコア戦略」の定義のままです（今回は変えていません）。

#### 代用データ（`F代用` 列）

定義どおりのデータが手元に無い項目は、次の代用で判定します。データが入れば自動で本来の定義に切り替わります。

| 項目 | 本来のデータ | 無いときの代用 |
|---|---|---|
| F4 | 特別損益前の純利益（Yahoo `NormalizedIncome` → `特別損益前純利益` 列） | 当期純利益 |
| F5 | 長期借入金（Yahoo `LongTermDebt` → `長期借入金` 列） | 有利子負債 |
| F7 | 株式の発行による収入（Yahoo `IssuanceOfCapitalStock` → `株式発行収入` 列） | 発行済株式総数が増えていないこと |
| F8 | 売上総利益（Yahoo、無ければ EDINET DB の `cost_of_sales_by_year.csv`） | 営業利益率 |

F4・F5・F7の3列は2026-10-06に `fetch_fundamentals.py` へ追加した項目で、Yahooから取り直した銘柄から順に入ります。
全銘柄を一度に入れたいときは `./.venv/bin/python fetch_fundamentals.py --refresh` を実行してください。
F8は EDINET DB の売上原価の蓄積（README_売上原価.md）が進むほど、代用が減ります。
EDINET の値は売上高がYahooと2%以内で一致する年度だけ使います。

#### スコアを出さない銘柄

次のいずれかに当てはまると採点せず、理由を `Fデータ品質` に残します。約3,000銘柄で算出できます。

- 3期分の決算がそろっていない
- 判定に使う項目（総資産・売上高・営業CF・当期純利益・流動資産・流動負債、借入金、売上総利益か営業利益）が
  直近期か前期で欠けている
- 隣り合う期で値が完全に一致している。データ元（Yahoo）で前期の値がそのまま持ち越された
  と疑われるケースです（無借金で0同士の場合は除く）
- 金融4業種（売上総利益と流動比率の概念が標準化財務諸表に無いため）

#### 予想Fスコア（会社予想ベース）

マネックス証券「復活Fスコア戦略」（2026年9月）と同じく、F1〜F3・F7を**今期の会社予想**で判定する版です。
計算は `forecast_fscore.py`、列は `予想Fスコア` と `予想F1営業利益` 〜 `予想F9株式発行`、
採点できなかった理由は `予想Fデータ品質` に入ります。

| 番号 | 1点の条件 |
|---|---|
| F1 | 今期予想営業利益がプラス |
| F2 | 今期予想営業利益÷前期末総資産 ＞ 前期営業利益÷（前期末と前々期末の総資産の平均） |
| F3 | 今期予想営業利益率 ＞ 前期営業利益率 |
| F4 | 前期の営業CFがプラス |
| F5 | 前期の流動比率 ＞ 前々期 |
| F6 | 前期の有利子負債÷総資産 ＜ 前々期 |
| F7 | 今期予想売上高÷前期末総資産 ＞ 前期売上高÷前々期末総資産 |
| F8 | 前期の当期純利益 ＜ 営業CF |
| F9 | 前期の発行済株式総数が前々期から増えていない（代用） |

- 会社予想は **J-Quants の fins summary**（決算短信サマリー）から取ります。`fetch_jq_summary.sh` が
  `fundamentals/jq_summary/開示日.json` を毎日1件ずつ取り足します（`run_fundamentals.sh` から自動で呼ばれます）。
- 同じ期の予想が何度も出ていれば、最新の開示（業績予想の修正・四半期決算の通期予想）を使います。
- 前期の売上高・営業利益・総資産・営業CF・純利益は、予想と同じ決算短信の値を優先し、無ければYahooの値を使います。
- **Freeプランは12週間遅れ**なので、直近12週間の予想修正は入りません。
- 実績は2期分あれば判定できます（実績ベースのFスコアは3期必要）。
- 採点しない銘柄：会社予想が無い（未開示・レンジ予想の会社。電力の一部など）、有利子負債などが欠けている、
  J-Quantsに新しい本決算があるのにYahooの実績がまだ追いついていない、金融4業種。

## 上場廃止銘柄の除外

TOBや経営統合で上場廃止になった銘柄は、株価が止まったまま残り続けます。
古い株価でPERや時価総額が計算され、ランキングに混ざってしまうため、既定で除外しています。

判定は**2つの条件がそろったとき**だけです。

1. JPXの銘柄一覧（`tickers/sectors.csv` の `listed` 列）に載っていない
2. 株価が市場の最新日から **7日以上**（`DELISTED_STALE_DAYS`）止まっている

片方だけでは足りません。JPXの一覧は月末時点なので**新規上場は載っていない**（ただし株価は最新）。
逆に株価の遅れだけで切ると、売買の薄い銘柄や取引停止中の銘柄まで落ちてしまいます。
実際、この2条件にしたことで上場廃止の7銘柄だけが正しく外れ、
株価が止まっていても上場中の2銘柄（日本ドライケミカル・ジェイ・エス・ビー）は残りました。

除外された銘柄は実行時にログへ出ます。残したいときは `--keep-delisted` を付けてください。

```bash
./.venv/bin/python analyze_fundamentals.py --keep-delisted
```

各銘柄の株価の遅れは `スコア一覧.csv` の `株価遅延日数` 列で確認できます。

## 総合評価の作り方（四季報式）

会社四季報の「業績評価」と同じ考え方で、**6つの項目をそれぞれ1〜5で評価し、その平均を
もう一度1〜5に区分**します。順位ではなく決まった基準で区切るので、去年と今年の評価を
そのまま見比べられます（順位ベースだと、全体が悪化しても上位2割は必ず高得点になってしまう）。

| 項目 | 元にする数値 | 5 | 4 | 3 | 2 | 1 |
|---|---|---|---|---|---|---|
| 成長性 | 売上高CAGR（直近4期） | 10%以上 | 5〜10% | 2〜5% | 0〜2% | 0%以下 |
| 収益性 | 売上高経常利益率の4期平均（IFRS等は税引前利益） | 11%以上 | 7〜11% | 4〜7% | 2〜4% | 2%未満 |
| 安全性 | 自己資本比率（直近本決算） | 80%以上 | 60〜80% | 40〜60% | 20〜40% | 20%未満 |
| 規模 | 時価総額（前営業日終値ベース） | 1.5兆円以上 | 5,000億〜1.5兆円 | 2,000〜5,000億円 | 500〜2,000億円 | 500億円未満 |
| 割安度 | 会社予想PER（時価総額÷今期予想純利益。予想なしは実績PER） | 10倍未満 | 10〜15倍 | 15〜30倍 | 30〜80倍 | 80倍以上 |
| 割安度（赤字・予想赤字時） | PBR（株価÷1株純資産） | 0.5倍未満 | 0.5〜1.0倍 | 1.0〜2.0倍 | 2.0〜4.0倍 | 4.0倍以上 |
| 値上がり | 250営業日前比の騰落率 | 上位20% | 上位20〜40% | 中位 | 下位40〜60% | 下位20% |

総合評価は6項目の平均を **4.5以上→5／3.5〜4.5→4／2.5〜3.5→3／1.5〜2.5→2／1.5未満→1**
に区分したもの。**3項目以上そろわない銘柄は評価しません。**

現在の分布（3,699銘柄）:

| 総合評価 | 銘柄数 |
|---|---|
| 5 | 19 |
| 4 | 960 |
| 3 | 1,969 |
| 2 | 668 |
| 1 | 81 |
| 評価不能 | 2 |

### 業種内偏差値

同じ業種の中で、その銘柄の**評価平均**が平均から何標準偏差ぶん離れているかを50±10で表します。

    業種内偏差値 = 50 + 10 × (評価平均 − 業種の平均) ÷ 業種の標準偏差

- 50がその業種のちょうど真ん中、60で上位16%、70で上位2%あたり
- 1〜5の総合評価は同点が数百銘柄になるので、丸める前の**評価平均**を使います
- 母集団はその業種の全銘柄なので標準偏差は ddof=0。画面の絞り込みを変えても値は動きません
- **10社未満の業種では算出しません**（空運業5社・鉱業5社・石油・石炭製品9社の計21銘柄が空欄）
- 現在の範囲は 12.1〜77.3、中央値51.6

**業種をまたいだ比較に使えます。** 総合評価4の小売株と総合評価4の銀行株では、それぞれの
業種の中での立ち位置が違います。ランキングを偏差値で並べ替えると「自分の業種の中で
どれだけ抜けているか」の順になり、業種の当たり外れを均して銘柄を選べます。

### 四季報そのままではない3点

手元のデータの制約による代用です。画面の「指標の説明」タブにも同じ注記を出しています。

| | 四季報 | この分析 | 理由 |
|---|---|---|---|
| 成長性・収益性の期間 | 5期 | **直近4期** | データ元（Yahoo Finance の標準化財務諸表）が4期までしか持っていない |
| 収益性の利益 | 経常利益 | 経常利益（**取り込めていない期は税引前利益**） | Yahooに経常利益の区分が無いため、決算短信サマリー（J-Quants）から期ごとに差し込む（keijo_yosou.py）。IFRS・米国基準の会社は経常利益の区分が無いので税引前利益。何を使ったかは「収益性の基準」列 |
| 割安度のPER | 今期の会社予想 | 会社予想（**12週間遅れ**） | J-Quants無料版の短信サマリー。分割でズレないよう「時価総額（自己株式除く）÷今期予想純利益」で計算。予想を出さない会社は実績PER、予想赤字はPBR |

数字の意味は近いものの、**四季報の評価と一致するとは限りません**。

### 赤字銘柄の割安度はPBRで測る

赤字だとPERがマイナスになり、これを「激安」と読むのは誤りです。そこで**PERが0以下の銘柄と、
報告EPSの桁が合わない銘柄（`E`印）は、PBRに切り替えて割安度を出します**。利益が出ていない
会社の値打ちを何で測るかという問題に対する、資産バリューの考え方です。区切りは1.0倍
（解散価値）を真ん中に置き、その半値・2倍・4倍を目安にしました。

**資産で甘く見てもらえる抜け道にはなりません。** 赤字銘柄のPBR中央値は1.71倍で、黒字銘柄の
1.24倍より高いためです。この区切りだと赤字銘柄は1が22%・5が12%となり、黒字銘柄
（1が4%・5が21%）より辛口に出ます。

| | 割安度あり | PER基準 | PBR基準 | 評価不能 |
|---|---|---|---|---|
| 変更前 | 3,240 (87.6%) | 3,240 | — | 459 |
| 変更後 | **3,692 (99.8%)** | 3,240 | 452 | 7 |

残る7銘柄は債務超過で、純資産がマイナスのためPBRも意味を持ちません。総合評価が動いたのは
110銘柄で、資産面で割安な赤字株が上がり（1→2が43社、2→3が55社）、資産面でも割高な赤字株が
下がりました（3→2が8社）。どちらの指標で測ったかは `割安度の基準` 列に残ります。

### 値上がりだけは相対評価

他の5項目は決まった基準で区切りますが、値上がり率は相場全体が上げ下げすると水準が丸ごと

### 金融業の安全性は業法の健全性指標で測る

預金・保険契約準備金・顧客預り金が負債に積み上がる業態では、会計上の自己資本比率が
数%にしかならず（野村ホールディングス5.9%、大和証券グループ本社4.7%）、
そのまま80%・60%…の基準に当てると全社が最低評価になってしまいます。
そこで業種ごとに物差しを替えています。

| 業種 | 使う指標 | 規制上の水準 | 5 / 4 / 3 / 2 / 1 の区分 | 取得元 |
|---|---|---|---|---|
| 銀行業 | バーゼル規制の資本余裕度 | 国内基準4.0% / 国際統一基準7.0% | 8 / 6 / 4 / 2 %pt | 全国銀行協会・金融庁（自動・年1回） |
| 証券、商品先物取引業 | 自己資本規制比率 | 120%未満で業務停止命令 | 600 / 400 / 280 / 200 % | 日本取引所グループ（自動・四半期） |
| 保険業 | ソルベンシー・マージン比率（経済価値ベース） | 100%未満で早期是正措置 | 240 / 215 / 195 / 175 % | 各社IR（手入力・年1回） |
| その他金融業 | 純有利子負債÷自己資本（ネットD/E） | — | −0.5 / 0.5 / 2 / 5 倍（小さいほど良い） | 決算データ |

同じ業種に分類されていても、**規制指標を持たない会社は自己資本比率で評価**します。
保険業のＦＰパートナー・ブロードマインド等は保険代理店、証券業のジャフコ・スパークス・
インテグラル等はPE・資産運用会社で、実態は普通の事業会社だからです。
どの物差しで評価したかは `安全性の基準` 列と銘柄詳細で確認できます。

**大手証券の安全性が低めに出るのは指標どおり**です。自己資本規制比率は自己勘定の
リスク量を分母に置くため、トレーディング業務の大きい会社ほど低く出ます
（野村236%、大和308%に対し、対面中心の岩井コスモは745%）。

### 金融の安全性・収益性を評価しない版

同じデータから、**金融4業種の安全性と収益性を一律で評価不能にした版**も並行して作っています。
JPXの33業種分類でいう銀行業・保険業・証券、商品先物取引業・その他金融業の168社が対象で、
東洋経済の60業種分類の「大手銀行」「地方銀行」「証券・先物」「リース・消費者金融」
「損害保険」「生命保険」にそのまま対応します。健全性の指標が業態ごとに違い、事業会社と
同じ土俵では比べられないという立場を徹底したい場合に使います。

- 出力: `data/charts/fundamentals_nofin.html`（公開URLは `fundamentals_nofin.html`）
- 該当銘柄は**残り4項目（成長性・規模・割安度・値上がり）の平均**で総合評価を出します。2項目少ないぶん平均が振れやすくなります
- **収益性を外す理由**: 金融業の「売上高」は経常収益（受取利息・保険料・受入手数料の合計）で、事業会社の売上高とは中身が違います。
  売上高税引前利益率を同じ基準に当てると銀行の中央値は35%前後になり、ほぼ全行が最高評価の5に張り付きます
- 総合評価が動くのは金融167社のうち**44社**（その他金融15・銀行14・証券8・保険7。2026-11-02時点）。
  非金融3,516社は1銘柄も変わりません
- 画面上部のリンクで2つの版を行き来できます
- 作り方: `analyze_fundamentals.py --no-financial-safety --out fundamentals/analysis_nofin`
  → `make_fundamental_dashboard.py --src ... --out ... --badge ...`。日次バッチが両方作ります

**注意**: 東洋経済の60業種では、保険代理店（ＦＰパートナー等）やPE・資産運用会社
（ジャフコ等）は「損害保険」「証券・先物」に入らない可能性があります。この版はJPXの
33業種で線を引いているため、それらも評価不能に含まれます。

### その他金融業をネットD/Eレシオで測る理由

リース・クレジット・保証・取引所を会計上の自己資本比率で採点すると、**評価が逆転します**。

| 銘柄 | 自己資本比率 | 旧・安全性 | ネットD/E | 新・安全性 | ROE |
|---|---|---|---|---|---|
| 日本取引所グループ | 0.48% | 1 | **−0.64** | **5** | 17.7% |
| 三菱ＨＣキャピタル | 15.2% | 1 | 4.45 | 2 | 8.1% |
| アコム | 44.5% | 3 | 0.91 | 3 | 11.1% |
| 日本証券金融 | 0.89% | 1 | **14.98** | **1** | 7.7% |
| ウェッジホールディングス | 80.6% | **5** | −0.41 | 5 | −7.6% |

原因は2つあります。①日本取引所グループ・日本証券金融は清算基金や貸借取引の担保金など
**他人から預かった資産**が総資産に乗るため、自己資本比率が構造的に極小になる。
②リース・クレジットはレバレッジが商売そのもので、自己資本比率15%は健全な水準。
結果、39社中19社が最低評価になり、上位に来るのは赤字の小型株でした。

**純有利子負債÷自己資本**なら、預かり資産は借金ではないので分子に入らず、実際の借入依存
だけを測れます。安全性の分布は **19/8/8/2/2 → 5/9/5/11/9** と各段階に散り、39社すべてで
値が取れます。債務超過の銘柄は比率の符号が反転して意味を持たないため、計算に乗せず1にします。

**保険業は2026-11-02に10社すべて入力しました**（`fundamentals/insurance_solvency.csv`）。
基準日はいずれも**2026年3月31日**、出所は各社自身の開示（単独の開示PDF、ディスクロージャー誌・
統合報告書の資料編、IRの健全性ページ）で、第三者のまとめサイトは使っていません。
内訳は連結7社（東京海上・ＭＳ＆ＡＤ・第一ライフ・ＳＯＭＰＯ・Ｔ＆Ｄ・かんぽ生命・ソニーFG）と
単体3社（ライフネット生命、アニコム＝アニコム損害保険、ＳＢＩインシュアランスG＝SBI損害保険）です。

**2026年3月期から基準が変わりました。** 2026年3月31日に経済価値ベースのソルベンシー規制が
適用開始され（令和7年金融庁告示第74号・第75号）、従来基準のソルベンシー・マージン比率
（発動基準200%、水準600〜1,000%）は10社すべてで2026年3月末時点の算出が終了しました。
新規制の指標の**法令上の名称も従来と同じ「ソルベンシー・マージン比率」**で、各社は同じラベルの
まま中身を経済価値ベースに入れ替えています（ＭＳ＆ＡＤは同じ見出しで前年708.7%、当年219.2%）。
そのため区分も新しい水準に合わせ、`INSURANCE_MIN_SMR` を200→100、
`INSURANCE_SAFETY_CUTS` を 1000/800/600/400 → **240/215/195/175** に置き換えました。
旧区分のままだと10社すべてが400%未満で安全性1に張り付きます。

新基準での10社の分布は162〜334%で、安全性評価は **1が1社・2が2社・3が2社・4が3社・5が2社**。
`insurance_solvency.csv` に数値が入ったことで安全性のカバー率は 3,669/3,683（99.6%）→
**3,679/3,683（99.9%）** になりました。区分は新規制の初年度・10社のみの分布に合わせた暫定値で、
分布が動いたら見直す前提です。入れ方と注意点は
`fundamentals/insurance_solvency_README.txt`、調査の経緯と全社の出所URLは
`fundamentals/insurance_solvency_2026調査メモ.md` を参照してください。

なお**公開ページ（`fundamentals.html`）は金融の安全性を評価しない版**なので、この入力は
公開ページの保険10社の安全性には現れません。効くのは標準版（`fundamentals/analysis`）の
Excel・CSV と、ひと目でわかる画面・シグナルの元データです。

## 銀行の財務健全性はバーゼル規制で測る

会計上の自己資本比率（純資産÷総資産）は銀行では5%前後にしかならず、事業会社（中央値55%）と
同じ物差しに乗せると全行が最下位に沈みます。そこで銀行だけは**バーゼル規制上の自己資本比率**を使い、
**銀行79行だけの順位表**で採点しています（単位の違う数字を同じ列で比べないため）。

| 適用基準 | 使う比率 | 最低所要水準 | 該当 |
|---|---|---|---|
| 国際統一基準 | 普通株式等Tier1（CET1）比率 | 4.5% ＋ 資本保全バッファー 2.5% ＝ **7.0%** | 14行 |
| 国内基準 | コア資本比率 | **4.0%** | 65行 |

比率の生値は基準が違うと比較になりません（国内基準の9%と国際統一基準の12%は同じ土俵にない）。
そこで**最低所要水準を何%pt上回っているか＝資本余裕度**にそろえ、不良債権比率と合わせて採点します。

| 銀行の財務健全性 | 配点 |
|---|---|
| 資本余裕度（%pt） | 65% |
| 不良債権比率（低いほど高得点） | 35% |

G-SIBサーチャージ（三菱UFJ・三井住友・みずほへの1.0〜1.5%上乗せ）は銀行ごとに違い毎年見直されるため
含めていません。3メガの余裕度はその分だけ甘めに出ます。基準は `analyze_fundamentals.py` の
`MIN_CAPITAL` で変えられます。

### データの取得（自動）

出どころは全国銀行協会の「銀行別諸比率表」（都銀・信託・地銀・第二地銀 107行、連結ベース、2026年3月末）と、
金融庁「中小・地域金融機関情報一覧」の不良債権比率（2025年3月末）です。

このデータは年1回しか変わらないので、`run_fundamentals.sh` が
`bank_capital.csv` の更新から25日以上たった日に限って取りにいきます（月1回）。
**URLは年度が変わると数字も変わりますが、索引ページから最新年度のリンクを自分で探す**ので、
書き換えは不要です。索引の作りが変わって見つけられないときは控えのURLを使い、ログに警告を残します。
取得に失敗した日も手元のCSVがそのまま使われ、日次の処理は止まりません。

./.venv/bin/python fetch_bank_capital.py --download   # 同じことを単体で

各社の開示を見て数値を書き換えてください。URLは `MANUAL` の各行に書いてあります。

### 突き合わせの注意

公的な一覧は**銀行単体**の名前なのに、上場しているのは持株会社です。対応表は
`fetch_bank_capital.py` の `BANK_MAP` にあります。**複数の銀行を抱える持株会社
（めぶきFG・ふくおかFG・ほくほくFG・九州FG・山口FG・トモニHDなど10社）は、

## データの扱いで気をつけたこと

## Yahoo!ファイナンスと数字が違う理由

見比べたときにズレる代表的な2つです。どちらも誤りではなく、定義の違いです。

**PER — こちらは実績、Yahoo!は会社予想。**
Yahoo!ファイナンスのPERは「株価 ÷ **会社予想**EPS」（例：トヨタは会社予想EPS 265.55円で11.89倍）。
このツールは「株価 ÷ **実績**EPS」（トヨタは実績EPS 295.25円で10.61倍）です。
**特別損益があると差は極端になります。** ソニーは金融事業スピンオフで実績が最終赤字のため
PERはマイナスですが、Yahoo!の会社予想ベースでは19倍です。
会社予想EPSはこのデータ元（Yahoo Finance の標準化財務諸表）には含まれておらず、
yfinance の `forwardEps` はアナリスト予想なので会社予想とは一致せず（トヨタ324円 vs 会社予想266円）、
中小型株では空欄になります。実績値で統一するほうが全銘柄そろうため、この形にしています。

**時価総額 — 自己株式の扱い。**
Yahoo!やJPXは「株価 × 発行済株式総数（自己株式を**含む**）」で数えます。
以前このツールは自己株式を除いた株数で計算しており、トヨタで21%、NTTで11%小さく出ていました。
**現在はYahoo!・JPXと同じ自己株式込みに揃えてあります。**
ただし株数は直近本決算時点のものなので、**決算後に自己株式の消却があった銘柄はその分ずれます**
（トヨタは決算後に12億株を消却しており、Yahoo!より約7%大きく出ます）。
自己株式を除いた時価総額は `時価総額(自己株式除く)` 列に残してあります。

---

**PERは「株価 ÷ EPS（実績）」です。**
参考として「時価総額 ÷ 当期純利益」も `PER(時価総額ベース)` 列に併記しています。
両者は全体の99%で一致しますが、株式分割が報告EPSに反映されていない等で35銘柄は桁が合わず、
ニホンフラッシュのPER0.53倍のような「ありえない割安株」がバリュー株の上位に来てしまいます。
**定義は変えず、この35銘柄のPERだけスコアとスクリーニングから外し**、`E` の印を付けて
値は表に残しています。

**赤字銘柄のマイナスPER・マイナスPBRは「割安」ではなく0点。** 順位付けから除いたうえで
最低評価にしています。そうしないと、赤字が深いほど割安に見えてしまいます。

**一時要因で指標が歪んだ銘柄に `特` の印。** PERが2倍未満、ROEが60%超、純利益が4倍超の
いずれかに当たる102銘柄です。資産売却益などで一時的に利益が膨らんでいる可能性が高く、
翌期には元の水準に戻ります。消さずに残しているので、気になったら決算短信で中身を確認してください。

**決算が古い銘柄は既定で除外。** 決算期から400日以上経った275銘柄です。
ダッシュボードのチェックを外せば表示できます。

**経常利益は決算短信から取り込みます。** Yahooの財務データには経常利益の区分が無いため、
J-Quants の決算短信サマリー（fundamentals/jq_summary/）の経常利益を決算期で突き合わせ、
四季報式の収益性に使います。短信データは fetch_jq_summary.sh が毎日少しずつ過去2年分まで埋めるので、
経常利益で測れる期は日を追って増えます（当初はほとんどの銘柄が「経常利益1期＋税引前利益3期」）。
税引前利益率の4期平均も参考として「平均税引前利益率(%)」に残しています。

## 配当の質・成長の追加指標（DOEなど）

`fundamentals_by_year.csv`（最大4期）から計算し、スコア一覧・ダッシュボードの条件ビルダー・銘柄詳細に出します。

| 指標 | 計算 |
|---|---|
| DOE(%) | 配当総額 ÷ 期首・期末の平均自己資本。配当総額＝1株配当 ×（当期純利益 ÷ EPS）＝分割調整後の株数。100%超はデータ誤りとして除外 |
| 平均DOE(%) | 直近3期のDOEの平均 |
| DOE変化(%pt) | 直近期DOE − 前期DOE |
| 減配回数／連続増配期数 | 1株配当の前期比（±0.5%以内は据え置き扱い）。期間が最大4期なので連続増配期数は最大3 |
| 配当CAGR(%)・EPS_CAGR(%)・営業利益CAGR(%) | 始点と終点がともにプラスのときだけ |
| 平均ROE(%) | 純利益 ÷ 平均自己資本 の期間平均 |
| PEG | PER ÷ EPS_CAGR |
| FCF配当性向(%) | 配当総額 ÷ フリーCF |
| ネットキャッシュ比率(%) | ネットキャッシュ ÷ 時価総額 |
| 純有利子負債/EBITDA | マイナスは実質無借金 |

追加したスクリーニング: **DOE安定配当株**（DOE3%以上・平均DOE3%以上・減配なし・DOE前期比−1〜+3pt・自己資本比率30%以上・配当性向100%以下）、**連続増配株**（3期連続増配・配当CAGR5〜50%・配当性向70%以下・FCF配当性向100%以下）、**PEG割安成長株**（PEG1倍以下・EPS成長10〜50%・営業利益CAGR10%以上・平均ROE10%以上・純有利子負債/EBITDA3倍以下）。
変更前のファイルは `*.pre_doe` に残してあります。

## 新高値

`compute_new_high.py` が `data/prices/*.csv`（2016年8月以降の日足）から `fundamentals/new_high.csv` を作り、`analyze_fundamentals.py` が結合します。`run_fundamentals.sh` でベータ計算の前に毎回実行されます（約20秒・通信なし）。

| 指標 | 意味 |
|---|---|
| 新高値からの日数 | 最後に52週新高値（その日のザラ場高値 ≧ 前日までの250営業日の最高値）を付けてからの営業日数。0＝最新日に更新、250＝1年間更新なし |
| 新高値回数(20日) | 直近20営業日で52週新高値を付けた日数 |
| 52週高値乖離(%) | 終値 ÷ 52週高値（ザラ場）− 1 |
| 上場来高値からの日数／上場来高値乖離(%) | 手元データ全期間の高値で判定。2016年8月より前に上場した銘柄は「約10年来高値」 |
| 出来高倍率(5日/50日) | 直近5日の平均出来高 ÷ 直近50日の平均 |

1日で±50%を超える値動き（分割が価格に反映されていない疑い）がある銘柄は判定しません。
スクリーニング: **新高値ブレイク株**（5営業日以内に52週新高値・増収率10%以上・営業増益率10%以上・黒字）、**上場来高値更新株**（5営業日以内に上場来高値・黒字）。どちらも出来高倍率の高い順。

## 成長ブレイク株（営業増益の持続＋移動平均線＋横ばい上放れ）

- 営業増益率3期平均(%): 今期の会社予想（J-Quants）・前期・前々期の営業増益率の単純平均。予想が無ければ実績の直近3期。比較する前期の営業利益が0以下の期があると空欄。`営業増益率3期最低(%)` で1期だけの急増に押し上げられていないか確認できる
- 営業CF2期黒字: 直近2期の営業CFがともに0以上なら1
- 5/25/75/200日線乖離(%)・移動平均線の上の本数: 終値ベース（`compute_new_high.py` で計算）
- 横ばい上放れ: 直近5営業日を除く前60営業日の終値の値幅が20%以内で、最新の終値がその最高値を上回れば1
- 条件: 営業増益率3期平均15%以上・自己資本比率35%以上・営業CF2期黒字・4本の移動平均線すべてより上。並びは横ばい上放れ→営業増益率3期平均の順

### 計算の決まり

- **会社予想は12週間遅れ**（J-Quants Free）。「業績予想修正率」は最後に予想を変えたときの変化率、「予想修正からの日数」は開示日から今日までの暦日なので、最短でも84日前後になる
- 営業利益の予想が無い会社（銀行など）は経常利益、それも無ければ純利益で修正率を測る
- 決算サプライズ＝直近の本決算の営業利益 ÷ 決算発表より前に出ていた最後の会社予想 − 1
- クロス・雲抜けの「からの日数」は、**いまその状態が続いている銘柄だけ**値が入る（0＝最新日にクロス）。200日線のクロスは約1年分さかのぼる
- 市場＝プライムの時価総額加重（ベータと同じ作り。指数データが手元に無いため）
- 売買代金は 終値×出来高 の近似（VWAPが無いため）
- 株式分割が株価に反映されていない日（1日で±50%超）があると、その日より後のデータだけで計算する
- ドル円感応度は週次リターンをドル円（`ドル円モデル/usdjpy_ohlc.csv`）に回帰した係数（約2年）。＋なら円安で上がりやすい
- 規模は JPX の一覧を取り直した翌営業日から入る。入るまでは「規模」の絞り込みは選べない

## データの照合（公式データとの突き合わせ）  2026-11-02 追加

毎日の `run_fundamentals.sh` の中で、自前のデータを取引所・企業情報の公式データに合わせ、結果を `fundamentals/verify/` に出します。すべて無料（登録不要、または既存の無料キー）。

| 照合先 | 何を合わせるか | スクリプト |
|---|---|---|
| JPX 上場銘柄一覧・上場廃止／新規上場ページ | 銘柄の過不足・銘柄名・市場区分・33業種 | update_tickers.py / verify_data.py |
| EDINET（有価証券報告書。EDINET DB・EDINET API） | 売上高・営業利益・当期純利益、決算月、上場区分、自己株式数 | reconcile_edinet.py / verify_data.py |
| J-Quants 決算短信サマリー（TDnet の公式値、無料プランは約12週遅れ） | 有報で照合できない期の売上高・営業利益・純利益、Yahoo に無い新しい本決算の追加、期末株数・自己株数 | reconcile_edinet.py / shares_crosscheck.py |
| 株探（いまの発行済株式数） | 公式値とずれた銘柄だけ確認し、総数・時価総額を合わせる | verify_shares.py --codes-file |

- 優先順位は **有報 ＞ 決算短信 ＞ Yahoo**。2%超かつ100万円超ずれたら公式値に置き換える（金融4業種の売上高と外貨建ての会社は対象外）。
- 営業利益が公式値と合っているのに Yahoo の売上総利益が営業利益と同額なら、売上総利益・売上原価を空にする（販管費0はありえないため）。
- 置き換えた内容: `edinet_corrections.csv`（照合元の列つき）、株数: `shares_corrections.csv`、残っている不一致: `verify_YYYYMMDD.csv` と `summary.txt`。
- 「決算が古い」で残るのは、短信がJ-Quants無料プランの範囲（約12週前まで）より後に出て、有報もまだ取得できていない銘柄。時間がたてば自動で埋まる。
- 「銘柄の過不足」で残るのは、JPX一覧（月末時点）の後に上場廃止・新規上場した銘柄と、対象外の優先株・社債型種類株（問題なし）。
