# ヒートマップ

`data/charts/heatmap.html`（トップ画面「市場全体を見る」→「ヒートマップ」）を作ります。

- 市場：プライム / スタンダード / グロース / 日経225 / TOPIX / 全市場（タブ）
- 区分け：東証33業種 → 銘柄。業種の帯（または下の業種ランキング）をタップすると、その業種だけ拡大
- 色：騰落率（1日・1週・1ヶ月・3ヶ月・年初来・1年）。赤＝上昇、緑＝下落
- 大きさ：時価総額 / 売買代金（当日） / 売買代金（20日平均）
- 銘柄をクリック（PC）→ 分析ダッシュボード。スマホはタップで詳細パネル → 分析・チャートへ
- 拡大・移動：右下の＋／−（スマホは2本指で広げる、PCはトラックパッドのピンチ・Ctrl＋ホイール・ダブルクリック）。拡大すると配置し直すので小さな銘柄にも名前と騰落率が出る。ドラッグで移動、「全体に戻す」で元の表示
- 日付スライダー：約1年前までの各営業日の時点のヒートマップに切り替え（‹ › で1営業日ずつ、▶ 再生で自動送り、キーボードの←→も可）。
  過去データは `data/charts/heatmap_hist.js`（約4.6MB）に分けてあり、スライダーを触ったときだけ読み込みます。
  過去の時価総額は最新値を株価の変化で引き戻した概算、市場区分・業種・日経225構成はいまの区分のまま。過去の日付では「1年」は出ません
- 選んだ市場・期間・大きさはURL（#mk=…&p=…&s=…&dt=日付）とこの端末に保存されます

毎営業日 `run_daily.sh` の 3b-4 で自動更新（通信なし・数秒）。手動実行:

```bash
~/株分析/.venv/bin/python ~/株分析/ヒートマップ/make_heatmap.py
```

入力は既存データのみ：`tickers/tse_tickers.csv`・`tickers/sectors.csv`・`fundamentals/fundamentals_latest.csv`（時価総額）・
`fundamentals/nikkei225.csv`・TOPIX構成（`tickers/sectors.csv` の規模区分）・`data/prices/*.csv`。時価総額は決算データの値を最新終値で引き直した概算、売買代金は終値×出来高の概算です。
