# 理論株価（7手法＋需給・心理補正）

東証全銘柄の理論株価を **PER法・PBR法・DCF法・DDM・RIM（残余利益モデル）・はっしゃん式・東洋経済式（会社四季報、n＝10期）** の7手法で計算し、

7手法の中央値（ファンダ）に **需給補正・心理補正** を掛けたもの、**市場の織り込み**（業種PER帯・織り込み成長率）と比べます。

- 毎営業日 `run_daily.sh` の 2c で自動更新（最新の予想EPSを Yahoo から最大15分取り足してから計算）
- 予想EPSは Yahoo のアナリスト予想（あれば）→ J-Quants の会社予想 → 実績の順。初回に全銘柄を一気に取るなら `~/株分析/.venv/bin/python ~/株分析/理論株価/fetch_forecast_yahoo.py --all`（1〜2時間）
- 手動: `bash ~/株分析/理論株価/run_valuation.sh`

## 出力
| ファイル | 中身 |
|---|---|
| `data/charts/valuation.html` | ダッシュボード（トップ画面「市場全体を見る」の「理論株価」カード） |
| `fundamentals/valuation.csv` | 最新の全銘柄の結果 |
| `理論株価/output/理論株価_YYYY-MM-DD.csv` | 日付ごとの控え（60日分） |
| `理論株価/data/valuation.sqlite` | 全履歴（表 `valuation`：日付×コード、表 `meta`：その日の前提） |

## 前提を変えるには
`valuation.py` 先頭の `P`（リスクプレミアム・永久成長率・補正幅など）を書き換えて再実行。
無リスク金利は `ドル円モデル/data.csv` の日本10年国債利回りを毎日読みます。

計算式の詳細はダッシュボードの「読み方」タブにあります。

## はっしゃん式の指標（理論株価Webの項目）
`hashang_metrics.py` が `fundamentals/hashang_metrics.csv` を作る（事業比率・α値・相関度・株価/理論/配当トレンド・直近トレンド・出来高過熱・イナゴ指数・コア4条件・割安･収益性など）。決算が最大4期分のため長期系は取れる期間で計算。10年スコア・配当格付・投資難易度・株主優待・直近先行は出さない。

## 予想EPS・実績EPSの点検（2026-11-27 追加）
- Yahoo の今期予想の「前期EPS」（raw_analyst の yearAgoEps）が手元の実績EPSと同じ（±25%）なら、桁の確認（実績の0.33〜3倍）を外れても大幅増減益として採る（例: キオクシア）
- 実績EPSが「当期純利益÷株数」と25%超ずれるときは、Yahoo の前期EPSに近いほうを採る（決算データの取り違え対策）
- 今期予想EPSが来期予想・実績の2.5倍超（資産売却益など）のときは、PER法だけ来期予想EPSで計算（例: サッポロ）
- 米国版は forecast_yahoo.csv が無いので、analyst.csv（us_fetch_analyst.py）の今期・来期EPSを予想EPSに使う
- 株式分割で Yahoo の権利落ち日が実際とずれる場合は、fix_splits.py が実際の段差の日を探して直す（例: キーエンス 6861）
