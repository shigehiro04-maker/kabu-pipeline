# 売買シグナル メーター

テクニカルとファンダメンタルの売買シグナルを、全銘柄それぞれ速度メーターで表示するページです。

```bash
cd ~/株分析
./.venv/bin/python make_signal_dashboard.py   # 約40秒（通信なし）
open data/charts/signals.html
```

日次ジョブ（`run_daily.sh` の 3a）に組み込み済みで、チャート再生成のあとに毎営業日作り直され、
GitHub Pages にも一緒に公開されます。銘柄一覧（index.html）の上部からもリンクしています。

## 出力

| ファイル | 中身 |
|---|---|
| `data/charts/signals.html` | ダッシュボード本体（検索・メーター・内訳・60日の推移・市場全体と業種別の分布・騰落レシオ・ランキング） |
| `data/charts/sig/<コード>.js` | 売買の目安チャート用のローソク足・一目・出来高（銘柄ごと） |
| `fundamentals/analysis/シグナル一覧.csv` | 全銘柄のスコア・判定・内訳（Excelで開けます） |
| `logs/signals.log` | 実行ログ（判定ごとの銘柄数） |

`index.html` 同様、`signals.html#7203` のようにコードを付けて開くとその銘柄を表示します。

## 画面の構成（簡潔版）

上から順に、必要なところだけ開いて見る作りです。

1. **市場全体（1行）** — 騰落レシオ、テクニカル・ファンダの買い／売り比率、総合判定の銘柄数。「詳しく ▾」で分布の帯・騰落レシオのグラフ・業種別（さらに「業種別 ▾」）を開く
2. **選んだ銘柄の結論** — 総合判定（買い／やや買い／中立・様子見／やや売り／売り）と一言コメント、4つの小さなメーター（テクニカル・トレンド系・オシレーター系・ファンダ）、値動きのコメントとイベント。「内訳・推移を見る ▾」で指標ごとの内訳と60日の推移を開く
3. **シグナル一覧** — 1行1銘柄で テク／トレ／オシ／ファ／総合 をバッジで表示し、各バッジの横にスコアの数値（−100〜+100）を併記。右端の「イベント」列に直近のゴールデンクロス・MACD転換・RSI／ボリンジャーの過熱と、決算の注意（⚠決算が古い など）を表示（スマホ縦画面では列を詰めずに1行の高さをそろえ、横スクロールで全列を表示。コードと銘柄名は左に固定し、銘柄名・業種は固定幅で「…」省略）。タブで絞り込み、列見出しで並べ替え

総合判定は、テクニカルとファンダをそれぞれ 良好側＝+1・中立＝0・弱い側＝−1 にして足したもの。
+2＝買い候補、+1＝やや良好、0＝中立（打ち消し合うときは「様子見」）、−1＝注意、−2＝避ける。
ファンダが無い銘柄はテクニカルだけで やや良好／中立／注意。

## 2026-10-13 の見直し（`シグナル再評価_20261013/`）

2017〜2026年の株価で過去にさかのぼって検証し、式と呼び方を変えた。

- 旧テクニカル（移動平均・MACD・一目 各20、RSI・ボリンジャー 各15、出来高10、合計×2）は先のリターンをほぼ当てなかった（20日先の順位相関 0.002）
- 新テクニカル（52週高値への近さ25・値動きの小ささ25・移動平均15・一目10・出来高10・MACD/RSI/ボリンジャー各5）は 0.046（t=2.5）、60日先 0.078（t=3.4）。2017-20／2021-23／2024- の3期間ともプラス
- 効き目は下位に集中（新テクニカル五分位の20日超過: −0.58, +0.29, +0.22, +0.08, 0.00%）。そのため「強い買い」はやめ、判定を 良好／やや良好／中立／弱い／避ける に変えた。「避ける」は全体の下位約2割
- ファンダは割安度の重みを25→55%。割安度に PBR と EV/EBITDA を加えた（2022-2026年の検証で、近似の旧式 IC 0.037 → 新式 0.098）
- 検証したが入れなかったもの：業績予想の上方修正（無料のJ-Quantsは12週遅れで、遅れて使うと有意でない。すぐ使えても月別の t=0.3〜1.7）、銘柄別の信用残（日次の蓄積が約2週間分で検証できない）

## 売買の目安（IN・利確・損切り）

銘柄の結論カードの下に、個別の価格の目安をチャートで出しています。直近100営業日（スマホ幅では60日）の
**ローソク足**（陽線＝赤・陰線＝緑。個別チャートと同じ色）、**一目均衡表**（転換線・基準線・遅行スパン・雲。雲は26日先まで）、
**出来高**の上に、INゾーン（青い帯）・利確1/2（青の破線）・損切り（実線）・保有中の手じまい（点線）・転換ライン（灰色の破線）を重ね、
右端に価格のラベルを並べます。一目均衡表と売買の目安はチェックボックスで表示を切り替えられます。
表示範囲から遠く外れる目安（例: 利確2）はラベルに ↑／↓ を付けて端に置きます。

チャートのデータは銘柄ごとに `data/charts/sig/<コード>.js`（1銘柄 約5KB、全体で約20MB）に分けて書き出し、
銘柄を開いたときだけ読み込みます（ページ本体は重くなりません。GitHub Pages にも一緒に公開されます）。
ファイルが無い場合は終値の線だけのチャートで表示します。
文章の要約と価格の一覧表は「目安の詳細 ▾」で開きます（銘柄を切り替えても開閉の状態は保ちます）。

| 表示 | 条件 | 出す目安 |
|---|---|---|
| **IN可** | 上昇トレンドで支持線のすぐ上（0.6ATR以内）、または売られすぎ | 支持線〜現値をINゾーンに |
| **押し目待ち** | トレンドが下向きでない、その他 | 一番近い支持線±0.3ATR を指値の目安に |
| **様子見** | トレンド系が売り以下 | 25日線・基準線などの「転換ライン」を終値で上抜けたら検討。保有中は戻り売りの目安と手じまいライン |

- 支持線・抵抗線：25/75/200日線、ボリンジャー±2σ、一目の基準線・雲、20/60日の高値安値、52週高値（0.4ATR以内に重なる線は1つにまとめる）
- 損切り：INゾーン下限−1.5ATR（間に次の支持線があればその0.3ATR下）
- 利確1・2：IN基準から1〜6ATR上の抵抗線（無ければ2ATR・4ATRの値幅）。リスクリワード＝利確1までの値幅÷損切りまでの値幅
- 保有中の手じまい：終値−2.5ATR（上昇トレンド中で25日線の方が上なら25日線−0.3ATR）
- 価格は呼値の単位に丸めています。一覧に「INゾーン到達」タブ、CSVに IN判定・IN下限/上限・転換ライン・損切り・利確1/2・リスクリワード・保有中の手じまい・ATR の列を追加
- 9/18終値時点の内訳：押し目待ち 2,037／様子見（転換待ち）863／IN可 797 銘柄

## 業種別のシグナル分布

普段は閉じています。市場全体の「詳しく ▾」を開いた中の **業種別 ▾** ボタンで開閉します。

33業種それぞれについて、テクニカル・ファンダの判定（強い売り〜強い買い）の銘柄数の割合を帯で、
平均スコアと買い比率・売り比率を数字で並べます。

- 並べ方: テクニカル平均／ファンダ平均／各買い比率／銘柄数／業種名
- 「市場全体」の横の市場セレクタ（プライム・スタンダード・グロース）で、市場全体と業種別の両方を絞れます
- 業種をタップすると、下のランキングがその業種（と選んだ市場）に絞られます
- 帯にカーソルを載せる（スマホはタップ）と、その判定の銘柄数が出ます

## テクニカルのトレンド系／オシレーター系

テクニカルのメーターの下に、2つの小さなメーターを出しています（合計のテクニカルスコアとは別集計、2倍の伸ばしなし）。

| | 指標（重み） | プラスの意味 | 判定の区切り |
|---|---|---|---|
| トレンド系 | 移動平均20・MACD20・一目20・出来高10 | 上昇トレンド | ±20 / ±50 |
| オシレーター系 | RSI15・ボリンジャー15 | 売られすぎ（逆張りの買い） | ±35 / ±70 |

- 判定の呼び方（2026-09-24 変更）：トレンド系＝強い上昇トレンド／上昇トレンド／横ばい／下降トレンド／強い下降トレンド、オシレーター系＝強く売られすぎ／売られすぎ／中立／買われすぎ／強く買われすぎ。メーターの両端にも「下降・上昇」「買われすぎ・売られすぎ」と表示（右＝買い側で4つのメーターを統一）。一覧のバッジは「上昇／下降」「売られすぎ／買われすぎ」（パソコン幅では「強く〜」まで表示）、CSVの判定列も同じ言葉。株式分析ダッシュボード（one_screen_template.html）も同じ表示
- 2つの組み合わせでコメントを出します。押し目＝トレンド系が買い以上かつオシレーター系が0以上、戻り＝その逆
- 2つは強く逆向きに動きます（相関 −0.9 程度）。上昇トレンドの銘柄ほどRSIが高く「買われすぎ」側に出るためです
- ランキングに「トレンド 買い上位」「売られすぎ」「買われすぎ」「上昇トレンドの押し目」タブを追加
- CSVにトレンド系・オシレーター系のスコアと判定の列を追加

## 騰落レシオ

市場全体の欄に25日騰落レシオのメーターと、直近120営業日の推移（25日・10日）を出しています。

- 値上がり銘柄数の合計÷値下がり銘柄数の合計×100（手元の株価CSVの前日比から計算）
- 市場セレクタで全市場／プライム／スタンダード／グロース別に切り替え
- 区切り: 70%以下 底値圏／80%以下 売られすぎ／120%以上 過熱気味／130%以上 過熱
- 手元の調整後終値から数えているので、日経などが公表する値とは少しずれることがあります

## スコアの作り方

どちらも −100（強い売り）〜 +100（強い買い）。各指標を −1〜+1 に換算し、重みを掛けて合計したもの。

| テクニカル | 重み | | ファンダメンタル | 重み |
|---|---|---|---|---|
| 52週高値への近さ（終値÷52週高値。97%以上+1・82%で0・67%以下−1） | 25% | | 割安度（割安度評価・PBR・EV/EBITDAの平均） | 55% |
| 値動きの小ささ（60日・年率。15%以下+1・35%で0・55%以上−1） | 25% | | 収益性（収益性評価＋ROE） | 10% |
| 移動平均（25/75/200日） | 15% | | 成長性（成長性評価＋増収率） | 5% |
| 一目均衡表 | 10% | | 安全性（安全性評価） | 10% |
| 出来高（上昇日の出来高比率） | 10% | | Fスコア | 10% |
| MACD・RSI・ボリンジャー | 各5% | | キャッシュ（FCF利回り、金融は除外） | 10% |

- テクニカルの乖離・差は直近20日の値動きの大きさで割ってから換算（銘柄間でそろえ、日々の跳ねを抑える）
- テクニカルの合計は伸ばさずに表示（`TECH_GAIN`=1。5〜95%点がおよそ−60〜+60）
- ファンダの1〜5評価は `analyze_fundamentals.py` の四季報式評価をそのまま使う（絶対評価なので市場全体が割安だと買い側に寄る）

| 判定 | テクニカル | ファンダ |
|---|---|---|
| 良好 | +40以上 | +45以上 |
| やや良好 | +15以上 | +20以上 |
| 中立 | −15〜+15 | −5〜+20 |
| 弱い | −15以下 | −5以下 |
| 避ける | −30以下 | −20以下 |

重み・区切りは `make_signal_dashboard.py` 冒頭の `TECH_W` / `FUND_W` / `LEVELS` / `TECH_GAIN` で変えられます。

## 注意

機械的に計算した参考指標で、売買の推奨ではありません。テクニカルは過去の値動きだけ、
ファンダは直近の本決算だけを見ており、今期予想やニュースは反映していません。
