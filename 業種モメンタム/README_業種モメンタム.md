# 業種モメンタム（第6章 試験運用）— 2026-10-12

『Algorithmic Trading』第6章の検証（`../モメンタム_第6章_20261012/`）で残った「業種モメンタム」を、**お金を入れずに**毎日記録する仕組み。
目的は、寄り前ギャップ（逆張り）と混ぜたときに値動きが打ち消し合う効果（検証ではシャープ 0.81→0.90、最大DD −34%→−17%）が実際にも出るかを確かめること。
**ルール・判定基準・停止基準は `PREREG.md`（2026-10-12 固定）**。記録が始まってからは変えない。

## ルール（要約）
| 項目 | 内容 |
|---|---|
| 判断 | 毎月の最終営業日の終値で、東証33業種を「対象銘柄の過去12か月（252営業日）のリターンの平均」で順位付け |
| 対象銘柄 | 内国株式・60営業日の売買代金中央値 1億円以上・終値 100円以上。業種は対象5銘柄以上 |
| 持つもの | 上位5業種（参考に下位5業種・全業種平均） |
| 記録 | 判断日の翌営業日の終値から。LS＝上位5−下位5、超過＝上位5−全業種、組み合わせ＝ギャップ(k=1)×0.3＋LS×0.7 |
| 判定 | 24か月目（2028-10末）に1回。停止：LS が最高値から −25% |

最初の判断日は **2026-10-30**（記録は 11/4 から）。それまで画面には「いまの終値で計算した参考の順位」が出る。

## 毎日の流れ（run_daily.sh の 3b-6、通信なし・十数秒）
1. `sm_signal.py` … 月末の営業日なら `output/signals/<判断日>.csv` を作る（処理が止まって月末を逃しても、次の実行でその月末の株価までで作る）
2. `sm_record.py` … `output/record_daily.csv` に新しい日だけ足す（既存の行は書き換えない）
3. `sm_page.py` … 画面 `data/charts/sector_mom.html`（トップ画面のカード「業種モメンタム」から）と `sector_mom_summary.json`

## 再現の確認（replay_check.py）
本番と同じ関数で 2017-09〜2026-09 の月末を順に判断（その月末までの株価だけ）：
LS 年率 +6.1%・シャープ 0.48・最大DD −20.7%、超過 年率 +4.2%・0.54・−16.5%（コスト前）。第6章の検証（21営業日ごと）との月次相関 **0.938**。
試しに 2026-08-31・09-30 を判断として流した記録は、再現の日次と完全に一致（差 0）。Mac の .venv（pandas 3.0.5）と Cowork（pandas 2.3）で同じ値。

直近の判断（再現）: 2026-09-30 上位 銀行業・非鉄金属・電気機器・金属製品・精密機器。

## 手で動かす
```bash
cd ~/株分析
./.venv/bin/python 業種モメンタム/sm_signal.py [--asof YYYY-MM-DD]   # --asof は試し用（SM_OUT=/tmp/x を付けると本番の記録を汚さない）
./.venv/bin/python 業種モメンタム/sm_record.py
./.venv/bin/python 業種モメンタム/sm_page.py
./.venv/bin/python 業種モメンタム/replay_check.py 2017-09 2026-09   # 約30秒
```
元に戻す: `run_daily.sh.pre_sectormom`・`make_home.py.pre_sectormom` が変更前。
