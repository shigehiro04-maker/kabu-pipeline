# 事前登録：業種モメンタムの試験運用（2026-10-12 固定。記録が始まってからは変えない）

『Algorithmic Trading』第6章の検証（`../モメンタム_第6章_20261012/README_モメンタム_第6章.md`）で、
33業種の12か月モメンタムは弱いプラス（t≈1.5）、寄り前ギャップとの月次相関 0.12、混ぜるとシャープ 0.81→0.90 だった。
ただし 10/5 の事前登録検証（TOPIX-17業種ETF）では効いていない。**お金を入れずに**記録し、組み合わせの効果が実際にも出るかを確かめる。

## ルール（検証の「等加重・12-0・上位5」と同じ。違いは判断日を月末にそろえた点だけ）
| 項目 | 内容 |
|---|---|
| 判断日 | 毎月の最終営業日の終値（日次処理の中で、その日が月末なら作る） |
| 銘柄の対象 | 内国株式で、判断日まで60営業日の売買代金の中央値 1億円以上・判断日の終値 100円以上（株価CSV、分割調整済み） |
| 業種の点数 | 東証33業種ごとに、対象銘柄の「判断日の終値 ÷ 252営業日前の終値 − 1」の単純平均。対象銘柄が5未満の業種は除く |
| 持つもの | 点数の上位5業種（買い）。参考として下位5業種（売り）と、全業種の平均も記録する |
| 業種の値動き | その業種の対象銘柄（判断日に固定）の日次リターンの単純平均（毎日均等に戻す）。日次リターンは −50%〜+100% で打ち切る |
| 記録の開始 | 判断日の翌営業日の終値から（＝判断日の2営業日後のリターンから）。次の判断日の翌営業日の終値まで |
| 主な指標 | ① 上位5 − 全業種平均（買いのみの超過）② 上位5 − 下位5（ロングショート）|
| 組み合わせ | 寄り前ギャップ（k=1）の日次損益 × 0.30 ＋ 業種モメンタム LS の日次 × 0.70（検証期間の月次ボラの逆数で決めた重み。固定） |
| コスト | 引かない（検証では月の入れ替わり約26%、片道0.1%で年約1.3%） |

最初の判断日は 2026-10-30、記録は 2026-11-04 から（11/2 の終値から 11/4 の終値までのリターンが最初）。※11/3 は祝日

## 判定（24か月目＝2028-10 末の記録で1回だけ。途中で基準を変えない）
「実際のお金で小さく始める候補」にするのは、次をすべて満たしたとき。
1. LS の月次平均 > 0 で t ≥ 1.0（24か月）
2. 上位5 − 全業種平均 の月次平均 > 0
3. 寄り前ギャップ（k=1）との月次相関 ≤ 0.30
4. 組み合わせのシャープ ≥ 寄り前ギャップ単独のシャープ（同じ期間）

## 途中でやめる基準
- LS の累計が記録開始からの最高値より −25% 下がったら停止（検証の最大DD −18.5% より悪い）
- 12か月目（2027-10 末）は確認だけで、判定はしない

## 注意（事前に分かっている弱点）
- 33業種の等加重バスケットはそのまま買えない。実際に使うなら TOPIX-17業種ETF などでの代用が必要で、10/5 の検証ではその形では効いていない
- 検証で効いたのは 2021年以降だけ。2017〜20年はほぼゼロ
- 株価CSVは現在上場の銘柄だけ。記録期間中に株価が無くなった銘柄（上場廃止など）は、その日から業種の平均に入れない
