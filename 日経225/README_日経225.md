# 日経225 入れ替え予想・ウエート分析

日経平均プロフィル（indexes.nikkei.co.jp）の**無料で公開されているデータ**と、手元の株価CSVだけで、

1. **次回の定期見直し（4月・10月）で採用・除外されそうな銘柄**を、日経の選定基準を再現して予想
2. 株価換算係数から**ウエート・寄与度**を計算し、**キャップ（ウエート10%）**を監視
3. 過去の入れ替えで**採用・除外銘柄がどう動いたか**を検証し、売買ルールの目安を出す
4. 銘柄ごとの「日経225」列を**ファンダメンタル分析のスコア一覧に結合**（スクリーニング「日経225採用候補」）

毎営業日、`run_daily.sh` から自動で更新されます（約30秒）。

## 日経の選定基準（2026年10月1日適用）と、このツールの再現方法

| 日経のルール | このツール |
|---|---|
| 東証プライムを「過去5年の売買代金」と「売買代金当たりの価格変動率（高値÷安値／売買代金）」で順位付け | 終値×出来高の1日平均（5年）と、(高値÷安値−1)の1日平均÷売買代金 の、2つの順位の和で並べる。上場1年未満は対象外 |
| 上位450＝高流動性銘柄群。採用銘柄で451位以下は除外 | 同じ（絶対除外。確度「高」） |
| 未採用で75位以内は採用 | 同じ（絶対採用。確度「高」、61〜75位は「中」） |
| 7セクター（技術・情報通信・金融・消費・素材・資本財その他・運輸公共）ごとに高流動性銘柄の半数を「採用妥当数」とし、過不足を調整 | 東証33業種→日経36業種の対応表（構成銘柄は日経の公式の業種で上書き）でセクターを決めて同じ計算（確度「中」） |
| 同一セクター内で既採用の最下位と未採用の最上位の順位差が最大のセクターで入れ替え | 順位差150以上のときだけ候補に（確度「低」。閾値は日経が非公表） |
| 1回3銘柄まで | 同じ。実績に合わせて「純粋なセクター調整」は1回1組まで |

日経は2指標の合成方法を公表していないので、順位は**近似**です。2023年4月〜2026年10月の8回の定期見直しで、
基準日までの株価だけを使って予想させると、**採用 16/18・除外 15/18 が的中**しました（Excelの「再現テスト」）。

**前回見送り**：前回の見直しでこの近似では75位以内だったのに、枠が空いていたのに採用されなかった銘柄（サンリオ・ゆうちょ銀行など）は、
日経の実際の指標では75位に届いていないとみなし、絶対採用の扱いにしません。

## 株価換算係数とウエートの計算

日経平均 ＝ Σ（株価 × キャップ調整済み株価換算係数）÷ 除数

- 日経は係数の一覧を無料では出していないため、2021年10月の公表一覧に、それ以降のお知らせ（入れ替え・株式分割・キャップ）
  をすべて当てはめて復元しました（`data/factors_seed.csv`、2026-10-01時点）。2026/10/1・10/2 の終値で日経平均と**誤差0.000%**で一致。
- 以後は毎日、日経のお知らせPDFを読み取り（`data/events.csv` に追記）、係数表を作り直します。お知らせから読めなかった株式分割は
  `data/splits.csv`（株価CSVの分割台帳）から「係数×分割比率」で補います。
- 毎日、計算値と日経平均の終値を照合します。0.05%を超えてずれたら、ダッシュボードに「ずれあり」と、
  ずれを説明できる銘柄と倍率の候補（Excelの「ずれの推定原因」）が出ます。

## 手で直すファイル（日経225/data/）

| ファイル | いつ直す |
|---|---|
| `exclude.csv` | 特別注意銘柄・上場廃止予定など、採用されない銘柄を足す（ニデックを登録済み。解除されたら行を消す） |

| `industry_override.csv` | 未採用銘柄の日経業種が東証33業種からの対応とちがうと分かったとき |

## 投資への使い方（過去の検証の要点）

- 採用銘柄は**基準日→実施前日**に対TOPIXで平均+5.9%（中央値+4.9%）、**実施後20日**は中央値−4.9%と反落しやすい。
- 予想どおりに「基準日の翌営業日に予想採用銘柄を買い、当たれば実施前日・外れたら発表翌日に手じまう」と、平均+4.4%（中央値+5.5%、20件）。
- 除外予想の空売りは平均−2.0%（損）で有効ではなかった。除外銘柄は発表後〜実施前日にむしろ上がることが多い。
- 需給インパクト（Excel）：連動資産額（黄色のセル）×採用時ウエートで、指数連動の買いが売買代金の何日分かを出す。連動資産の初期値10兆円は仮置き。

投資判断はご自身で。日経の公表ルールからの推定で、日経の公式予想ではありません。
